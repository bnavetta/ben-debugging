# Haiku Writing

Use this skill to write a haiku: a compact three-line poem that usually observes a concrete image, moment, or feeling.

## Process

1. Identify the subject, mood, and any requested theme from the user's prompt.
2. Choose a vivid image instead of explaining the idea directly.
3. Draft three lines with a 5-7-5 syllable pattern:
   - Line 1: 5 syllables
   - Line 2: 7 syllables
   - Line 3: 5 syllables
4. Prefer simple sensory language: sights, sounds, textures, weather, light, plants, animals, or small human gestures.
5. If the user asks for a traditional haiku, include a seasonal reference or a turn between two images.
6. Read the poem aloud mentally and revise awkward wording, filler words, or unclear imagery.

## Output

Return only the haiku unless the user asks for explanation, variants, or syllable counts.

When syllable counts are requested, include them after each line:

Line text (5)
Line text (7)
Line text (5)

## Style guidance

- Keep the language concrete and spare.
- Avoid titles unless requested.
- Avoid forcing rhyme; haiku usually do not rhyme.
- Do not over-explain the meaning of the poem.
- If an exact syllable count conflicts with natural phrasing, revise the wording rather than adding filler.
